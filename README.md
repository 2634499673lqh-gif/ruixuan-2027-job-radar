# 睿选机会｜2027届广东校招雷达

一个公开、可审计、每天自动运行的校招岗位网站，面向 **2027届毕业生**，只收录 **广东省内正式校园招聘**。

## 自动化流程

GitHub Actions 每天北京时间 08:00：

1. 并发读取 `config/sources.json` 中的企业官网、授权招聘系统与政府公开来源；
2. 提取普通链接及结构化 `JobPosting` 数据，筛选2027届、广东地点和目标岗位方向；
3. 排除实习、社招和其他毕业年份；
4. 对新增岗位去重并写入 `data/jobs.json`；
5. 独立岗位连续三次成功核查未出现后移入归档；
6. 采用两级地点可信度：具体岗位明确出现广东地点时标记“已核验”；可信来源及招聘范围指向广东但具体城市未明时保留为“广东地点待确认”；
7. 验证岗位数量、地点、性质、可信度等级和链接格式；
8. 验证通过后自动发布 GitHub Pages。

来源读取失败时不会清空岗位池；所有来源都失败时工作流直接终止并保留上一版网站。

## 岗位方向

- 产品、数据、AI、互联网运营
- 智能汽车与商品企划
- 跨境电商、海外运营、国际业务
- 商务专员、销售支持、跟单业务
- 供应链、采购、计划物流
- 银行、管培生等补充方向

## 本地运行

```bash
npm install
npx playwright install chromium
npm run update
npm run validate
npm test
npm run build
```

直接打开 `index.html` 可能受浏览器本地文件限制；建议使用任意静态文件服务器预览。

## 数据边界

- 只读取无需登录的公开页面，不保存或使用 GiveMeOC、招聘网站或个人账号 Cookie。
- 来源分为企业官网、企业授权招聘系统、政府/国资公开公告；聚合平台只用于发现线索，未经官方页面核验不会冒充确定岗位。
- “已核验具体岗位”表示具体岗位上下文已有广东地点证据；“广东地点待确认”仍进入活动岗位池，但投递前必须进入官网核对城市。只有明确省外的岗位才因地区原因归档。
- 自动发现结果不能替代企业最终公告；投递前仍须核验毕业时间、地点、专业和截止日期。
- 网站不会代替用户投递、发送邮件或联系招聘方。
- 招聘网站页面结构变化时，可能需要更新来源配置或解析规则。
